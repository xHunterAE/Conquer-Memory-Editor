# Conquer-Memory-Editor
Advanced Cheat Engine Lua-based memory automation for Conquer 3.0 . Includes auto pathing, pickup, and GUI forms.


## Features
- Memory scanning and code injection using Cheat Engine Lua.
- Automated monster hunting and reward collection.
- HWID authentication and licensing system.
- Anti-debugging protections.
- Custom Cheat Engine forms for GUI.
- Auto item pickup, auto-revive, and movement automation.
- FB/SS Skill Automated for any selected Player
- Auto Use HP Memory Based
- Auto Play without user intercation ( Bot plays better than u )

## Folders
- `/scripts/` : Lua and assembly injection scripts.
- `/forms/` : Cheat Engine forms (`.FRM` files) for the GUI.
- `/server/` : HWID and ban API scripts (PRIVATE).
